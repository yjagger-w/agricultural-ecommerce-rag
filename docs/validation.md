## 独立性能测量

环境：win32 x64，Node v24.19.0，SQLite 3.53.3，Intel(R) Core(TM) Ultra 7 255H，16 个逻辑处理器，内存 31.49 GiB。

数据：2000 张程序生成的虚构卡、4 个商品、4 个目录版本；4 类查询轮换。预热 100 次、串行 1000 次、并发 1。计时为 `performance.now()`；p50/p95 按排序后的 nearest-rank 分位数计算。

| 区间 | p50 (ms) | p95 (ms) |
| --- | ---: | ---: |
| 知识检索 | 1.699 | 3.886 |
| 路由 + SQLite 查询 + 检索 | 1.840 | 4.220 |

单次知识冷加载 95.092 ms，只记录样本，不代表冷加载分位数。测试用 SQLite 在内存中，知识索引预加载；不包含 HTTP、数据库文件打开、模型网络、并发排队或真实业务数据。没有保留 500 ms SLA。完整机器可读结果见 [benchmark-result.json](benchmark-result.json)，可用 `npm run benchmark` 独立复测。
